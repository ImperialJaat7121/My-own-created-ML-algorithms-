# Boosting (AdaBoost, Gradient Boosting, XGBoost)

Summary
- Implementations of AdaBoost (classifier & regressor), Gradient Boosting, and an XGBoost-like system with custom tree learner.

Files
- `adaboost/` — AdaBoost implementations and tests (`adaboost_classifier.py`, `adaboost_regressor.py`, test scripts and notebooks).
- `gradient boosting/` — gradient boosting classifier and regressor implementations plus tests and visuals.
- `xgboost/` — `XGBoostClassifier`, `XGBoostRegressor`, and supporting `XGBoostTree` implementation with tests and visuals.

Quick run
- See test scripts in each subfolder (e.g., `boosting/adaboost/test_adaboost_classifier.py`).

Notes
- These implementations rely on the tree learners under `trees/`.
